We include five examples in every language binding, namely, offline monitoring in discrete time, offline monitoring in dense time, online streaming, probabilistic monitoring, and synthesis. Each example is a self-contained program that you can run to see the monitor in action and it's purpose is to get you started quickly with SENTIL.

## The canonical set

<Cards>
  <Card title="Offline monitoring, discrete time" href="/docs/examples/canonical/offline-discrete" description="Evaluate a trace against a formula and read the robustness, the per-sample signal, and the violation intervals." />
  <Card title="Offline monitoring, dense time" href="/docs/examples/canonical/offline-dense" description="Read the same trace as a continuous signal so that a dip between two samples is counted." />
  <Card title="Online streaming" href="/docs/examples/canonical/online-streaming" description="Fold one timestamped sample at a time and read a running verdict." />
  <Card title="Checking a PrSTL property" href="/docs/examples/canonical/prstl" description="Register a sensor noise model, lift each reading into an ensemble, and estimate satisfaction probability with a confidence interval." />
  <Card title="Synthesis" href="/docs/examples/canonical/synthesis" description="Solve a specification for a control input, then shield a nominal controller with a safety filter." />
</Cards>
