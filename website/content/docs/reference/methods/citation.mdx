If SENTIL helped your work, please cite it. The tool comes from Paapa Kwesi Quansah and Ernest Bonnah at the SEDIS Lab, Baylor University.

## The paper

SENTIL is described in "SENTIL: A Runtime Verification Tool for Probabilistic Temporal Logic," with a preprint on arXiv at [arXiv:2605.21676](https://arxiv.org/abs/2605.21676).

```bibtex
@misc{quansah2026sentilruntimeverificationtool,
  title         = {{SENTIL}: A Runtime Verification Tool for Probabilistic Temporal Logic},
  author        = {Quansah, Paapa Kwesi and Bonnah, Ernest},
  year          = {2026},
  eprint        = {2605.21676},
  archivePrefix = {arXiv},
  primaryClass  = {cs.LO},
  note          = {Submitted to the International Conference on Computer-Aided Verification (CAV)},
  url           = {https://arxiv.org/abs/2605.21676}
}
```

## Citation metadata in the repository

The repository ships a `CITATION.cff` at its root, so GitHub's "Cite this repository" button offers the citation directly and tools that read the CFF format can convert it to BibTeX or other styles. The file records the authors, the version, the license, and the arXiv identifier.
