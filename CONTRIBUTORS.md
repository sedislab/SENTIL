## Contributing

Contributions of every kind are welcome: bug reports and fixes, new features, faster code, documentation and examples, tests and benchmarks, and design review. Start with [CONTRIBUTING.md](CONTRIBUTING.md), which covers the development setup, the house style, and a first pull request, including how to work on a language binding without a Rust toolchain.
